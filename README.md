# Steinwerk

Web-App, um LEGO-Sets zu erfassen, Teile abzuhaken, Anleitungen zu finden und unvollständige Sets wieder aufzubauen.

- Setdaten, Teilelisten und Bilder über die Rebrickable-API (eigener kostenloser API-Schlüssel nötig)
- Links zu Bauanleitungen bei LEGO, Brickset, Rebrickable und BrickLink
- Fotoerkennung von Teilen, Sets und Minifiguren über Brickognize
- Fehlteile-Export als BrickLink-XML oder Rebrickable-CSV

Alle Sammlungsdaten bleiben lokal im Browser des jeweiligen Geräts.
